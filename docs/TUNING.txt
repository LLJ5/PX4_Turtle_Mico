反乌龟模式调参说明

适用：当前 MicoAir H743 V2 固件，固定使用逻辑 Motor 1、4 反转，绕机体 +X 轴正向翻身。
这是说明和命令清单，不是 QGC 可直接导入的 .params 文件。
QGC MAVLink 终端请每次只复制一条命令，回车执行后再输入下一条。

一、主要调参源码

工程中实际参与编译的参数定义文件：
src/modules/turtle_recovery/turtle_recovery_params.c

独立阅读副本：
turtle_recovery_source/src/modules/turtle_recovery/turtle_recovery_params.c

通过 QGC 的参数界面或 param set 修改已有参数，不需要重新编译或刷机。
新增的 TRTL_NP_T、TRTL_DRV_T 需要先刷入本次新固件，之后可直接在线调整。
油门上限扩展到 0.80，以及新增 TRTL_THR_SLEW，也需要刷入对应新固件。
如果修改源码中的默认值，需要重新编译并刷机；飞控中已经保存的参数值不会因此自动替换。
先用 param show 查看实际数值，不要把源码默认值当成飞控当前值。

二、主要调节参数

参数名          源码默认值     允许范围        作用
TRTL_MAX_THR     0.2          0.05～0.80      1、4 号电机的 DShot 油门比例上限。
TRTL_THR_SLEW    0.25           0.10～1.00 /s 零滚速时油门比例每秒的上升量。
TRTL_R_RATE      120            30～200 deg/s  期望机体正向横滚角速度。
TRTL_REL_ANG     75             30～90 deg     停止出力时的剩余倾角参考值。
TRTL_NP_T        1.2            0.5～2.5 s     无明显正向滚转时的等待时长。
TRTL_DRV_T       2.5            0.5～2.8 s     总出力时长上限。

TRTL_MAX_THR：
  当前参数源码默认值已按用户修改保留为 0.20；飞控实际值仍用 param show 确认。
  前面的低油门试验路径为 0.12 -> 0.18 -> 0.20，每次单独观察效果后再调整。
  油门比例不是实际功率、推力或电机转速的百分比。0.80 也不是电机的最大转速。
  当前没有电机转速闭环；提高这个上限只是允许发送更高 DShot 油门指令。
  先检查停止原因和桨叶是否触地卡住。已试过 0.30 的机架，可从 0.35/0.40 继续小步试验。
  不要一次直接带桨跳到 0.80，也不要在桨叶堵转时继续加大输出。

TRTL_THR_SLEW：
  只控制油门上升速率，原有超过目标滚速时按 0.50/s 减油的行为保留。
  默认 0.25/s 下，从零到 0.80 约需 3.2 秒，超过本程序的最长出力时间。
  因此只增大 MAX_THR，不增大爬升率，并不能保证在本次尝试内达到该上限。
  例如设 0.50/s，静止时约 0.8 秒达到 0.40、1.6 秒达到 0.80。
  正向滚转会降低爬升速率，达到目标滚速时停止加油，过快时减油。
  时间过期、关开关、姿态异常或达到收油角仍会提前停机。

TRTL_R_RATE：
  单位是机体翻滚速度 deg/s，不是电机 RPM。
  它影响油门增长/降低的趋势，不保证精确跟踪设定角速度。
  当前先保持 120，不要同时改变多个参数。

TRTL_REL_ANG：
  倒扣约为 180 deg，正立约为 0 deg。
  数值减小通常意味着更晚停止出力；数值增大通常意味着更早停止出力。
  代码还按正向滚速预测 0.15 秒后的倾角，可能更早收油，并有过快停机保护。
  若已经明显翻滚、进入滑行但停在侧面，再单独评估从 75 调到 60。
  当前几乎没有抬起时，先调整油门上限。

TRTL_NP_T、TRTL_DRV_T：
  时间从进入出力阶段开始，包含油门爬升，不包含反转准备和停机恢复的等待。
  NP_T 时刻累计正向滚转不足 5 deg 则退出；到 DRV_T 时刻则停止出力。
  TRTL_NP_T 必须小于等于 TRTL_DRV_T；参数越界、非有限或时长关系错误会阻止启动。
  本次可先试 NP_T=2.0、DRV_T=2.8，其他参数保持当前值，以便单独观察时长的影响。
  关开关、失联、方向错误或达到收油角等条件仍会提前结束出力。

三、本次先执行的命令

先保持翻身开关 LOW、油门最低、普通解锁关闭，等待电机停止，
并确认 busy no、direction dirty no。参数变更在恢复过程中可能触发中止。
先查看当前上限：

param show TRTL_MAX_THR

以下为已试过 0.30 的机架继续验证的起点。先拆桨检查停机与转向恢复。
新固件不会自动把飞控已保存的油门上限改为 0.80。
逐条设置总时限、无进展时限、爬升率，再把油门上限小步改到 0.40：

param set TRTL_DRV_T 2.8

param set TRTL_NP_T 2.0

param set TRTL_THR_SLEW 0.50

param set TRTL_MAX_THR 0.40

再次查看确认：

param show TRTL_MAX_THR

倒扣放稳、离手后，再 LOW -> HIGH 进行一次尝试。
试验须确保桨叶能自由转动、人员离开桨盘，不带桨手持；异常立即 LOW 停机。
尝试结束后先保持 HIGH，读取状态以保留停止原因：

turtle_recovery status

dshot status

记录 Recovery progress、state 后的原因和驱动状态，再切回 LOW。
需要保存当前参数时执行：

param save

回到初始油门上限的命令：

param set TRTL_MAX_THR 0.12

四、增加反转出力时长

先刷入本次生成的固件：
build/micoair_h743-v2_default/micoair_h743-v2_default.px4

保持 LOW，等待电机停止、busy no、direction dirty no。
逐条执行，先增加总时长上限，再增加无进展等待时长：

param set TRTL_DRV_T 2.8

param set TRTL_NP_T 2.0

param save

turtle_recovery status

状态应显示 Drive time limits: no progress 2.0 s, total 2.8 s。
先拆桨验证时限、关开关停机和恢复转向，再在受控场地验证实际翻身。
无滚转时预计在出力约 2.0 秒退出；已有至少 5 deg 正向滚转但未收油时，最长约 2.8 秒退出。
这是出力阶段时长，首次 HIGH 后还要经过静止确认和反转准备。
改参数会取消当前尝试，所以只在停止、恢复完毕的 LOW 状态下调节。

回到原时间设置，逐条执行：

param set TRTL_NP_T 1.2

param set TRTL_DRV_T 2.5

param save

时间限制相关源码：

src/lib/turtle_recovery/TurtleFlipController.hpp：
  达到 TRTL_NP_T（默认 1.2 秒）且正向滚转不足 5 deg -> no roll progress。
  达到 TRTL_DRV_T（默认 2.5 秒） -> drive timeout。
  两者同时满足时优先报告 drive timeout。
  静止时油门从零按 TRTL_THR_SLEW（默认 0.25/s）上升；出现正向滚速后，增长会减慢。
  默认爬升率下，0.18 约需 0.72 秒、0.30 约需 1.2 秒、0.80 约需 3.2 秒。
  不能认为设置了更高上限就会立即以该值出力，也不能靠反复请求绕过时限。

src/lib/turtle_recovery/TurtleOutputGuard.hpp：
  DShot 后端有独立的 3 秒连续出力硬限制。
  DShot 后端的独立硬油门上限为 0.80，同时仍受 TRTL_MAX_THR 的更小设定值限制。
  控制请求超过 200 ms 未刷新会停止出力。
  反转前、恢复转向前均发送停机输出等待 500 ms。

本次保留后端 3 秒硬限制，控制器总时长上限设到 2.8 秒，留出停止响应余量。
若是 wrong roll direction、传感器失效或驱动退出，延长时限不能解决原因。

五、功能与输入参数

TRTL_ENABLE：默认 0；1 开启实际翻身输出。保存为 1 后，本板后续上电自动启动模块。
TRTL_OBS_EN：默认 0；1 开启观察和开关计数，不单独允许电机出力。
TRTL_AUX：默认 1；选择 AUX1～AUX6。
RC_MAP_AUX1：本机前面已确认使用 CH6；这是遥控通道映射，不是电机输出口。

所有尝试均要求未解锁、油门最低、有效遥控与传感器、倒扣静止和 LOW -> HIGH。
翻身开关 LOW 会停止出力；停止后等待驱动完成转向恢复。
TX 完成只说明飞控发送完命令，实际转向仍需拆桨核实。
当前保持正常飞行预检、急停、方向错误退出和恢复转向的解锁互锁。

六、使用 0.80 前需要理解的区别

本版本允许 TRTL_MAX_THR 的范围为 0.05..0.80；无需再修改其它代码来允许 0.80。
1.00 仍不在允许范围内。源码默认保持 0.20，TRTL_THR_SLEW 默认保持 0.25/s。
0.80 对应协议油门范围约 80%，不是 RPM 百分比，不保证固定转速或实际翻身推力。
高油门值要在转向、不卡桨、停机和恢复均已核实的基础上逐步验证。
爬升率参数和较长时限也不会阻止 LOW 停机；任何参数更新会取消正在执行的尝试。
停止后 status 的 throttle 会清零，不能用这个零值反推尝试期间从未出力。
