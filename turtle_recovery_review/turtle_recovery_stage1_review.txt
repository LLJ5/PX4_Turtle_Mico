PX4 自动右翻开发第一步 完整修改与中文说明

一、这一步做什么

硬件背景：Mico H743 V2 AIO、Bluejay 电调、已经能正常起飞的四旋翼。
本步骤增加 turtle_recovery 观察模块，检查遥控输入、四元数姿态、右翻角速度符号和右侧候选电机。
当前实现没有执行器消息发布，也没有 ESC 命令接口；它不能执行翻身。
观察到倒扣、落地状态或开关触发，不代表已经通过允许电机启动的检查。

二、改动清单

共 7 个实现文件：1 个已有文件增加一行，6 个新文件。
1. boards/micoair/h743-v2/default.px4board
   已有文件增加一行 CONFIG_MODULES_TURTLE_RECOVERY=y，把模块编入 Mico H743 V2 固件。这不会让模块自动启动。
2. src/modules/turtle_recovery/Kconfig
   向 PX4 配置系统注册 MODULES_TURTLE_RECOVERY。全局默认关闭，由上面的板级配置选中。
3. src/modules/turtle_recovery/CMakeLists.txt
   定义 turtle_recovery 控制台命令、编译源文件、工作队列依赖和单元测试入口。
4. src/modules/turtle_recovery/turtle_recovery_params.c
   定义 TRTL_OBS_EN 和 TRTL_AUX 两个参数。前者只允许观察开关触发，后者选择 AUX1 至 AUX6。
5. src/modules/turtle_recovery/TurtleObserver.hpp
   三个可独立阅读的逻辑：四元数计算机体向下轴与地面向下轴的对齐值；按 CA_ROTORn_PY 选择右侧逻辑电机；开关 OFF 到 ON 的单次触发。
6. src/modules/turtle_recovery/TurtleRecovery.cpp
   模块主体，每 20 ms 更新一次订阅数据；检查数据时效、RC 来源和未解锁状态；收到触发只打印日志；status 显示姿态、角速度和候选电机。
7. src/modules/turtle_recovery/TurtleObserverTest.cpp
   六项测试：完整横滚与四元数正负等价；俯仰 90 度；无效姿态；按几何位置选电机；启动或持续 ON 不重复触发；输入无效后重新观察 OFF。

三、阅读顺序与程序流程

建议先读参数文件，再读 TurtleObserver.hpp，最后读 TurtleRecovery.cpp。
Kconfig 与 CMakeLists.txt 用于让 PX4 找到并编译模块，测试文件用于核对基础行为。

TurtleRecovery::Run()
  -> 参数发生变化时更新参数和电机几何
  -> 读取 manual_control_setpoint、vehicle_attitude、vehicle_angular_velocity
  -> 读取 vehicle_status、vehicle_land_detected
  -> 选出 TRTL_AUX 指定的 AUX 输入
  -> 检查 RC 来源、数据有效性和时间戳
  -> 从四元数计算正反面和倾角
  -> 读取机体系 X 轴角速度
  -> 在观察已开启、RC 有效且未解锁时统计 OFF 到 ON 的触发
  -> 触发时只打印日志

TurtleRecovery::print_status()
  -> 显示观察是否启用、AUX 数值、OFF 是否已被看到、请求计数
  -> 显示姿态、角速度、落地检测参考信息
  -> 显示右侧逻辑电机候选列表

四、参数设置

TRTL_OBS_EN：新增参数，默认 0；设为 1 后允许统计观察开关触发。
TRTL_AUX：新增参数，默认 1；数值 1 至 6 分别表示 AUX1 至 AUX6。
RC_MAP_AUX1：已有参数；将一个空闲遥控通道映射到 AUX1。
本阶段保留现有 DShot、PID、电机几何及转向参数。

以下假设开关位于 CH7，且 AUX1 尚未被其他功能使用。
如果实际使用其他通道，替换示例中的 7；不要把 7 当作固定要求。

在 QGC MAVLink 控制台执行：

param set RC_MAP_AUX1 7
param set TRTL_AUX 1
param set TRTL_OBS_EN 1
turtle_recovery start
turtle_recovery status

模块通过控制台手动启动；重启飞控后需要重新执行 start。
首次启动开关如果已经处于 ON，必须先切到 OFF，再切到 ON。
更改观察启用状态或 AUX 选择后，同样需要重新观察到 OFF。
RC 输入无效或失效后，恢复连接并保持 ON 不会直接触发。

停止观察模块：

turtle_recovery stop

关闭观察开关统计：

param set TRTL_OBS_EN 0

五、坐标与状态字段解释

PX4 FRD 机体坐标：X 向机头，Y 向机体右侧，Z 向机体下方。
本方案固定右翻的数学定义：绕机体 +X 轴正向旋转；正立时表现为右侧向下滚动。
角速度符号是机体坐标定义，不能用操作者站位或倒扣后看到的屏幕左右判断。

body-down alignment：机体 +Z 轴与地面向下轴的点积。
  接近 +1：正立。
  接近 0：侧立。
  接近 -1：倒扣。

tilt：上述两个方向之间的夹角，以度显示，范围 0 至 180 度。
它没有记录完整翻转进度；0 到 180 再回到 0 不能区分左翻与右翻。
当前版本使用它验证正反面，未来控制器还需结合四元数相对旋转和角速度跟踪方向。

roll rate：机体 X 轴角速度，显示单位为度每秒；正值对应本方案规定的右翻方向。

right logical motor mask：按 CA_ROTORn_PY 大于零选出的逻辑电机位掩码。
当前只识别左右各两台电机的常规四旋翼布局；十字形等其他布局会显示 unsupported。
标准 PX4 X 型通常对应 Motor 1 和 Motor 4，掩码为 0x9；程序按实际参数选择。
这些是逻辑电机编号，不等于物理焊盘或输出通道号。

land detector：仅显示落地检测参考信息，本模块没有实现地面判定或电机输出许可。
observing / requests：只表示开关观察状态和触发计数，不表示已允许翻身。
invalid/stale：相应数据无效或已过期。

六、拆桨验证步骤

保持未解锁，拆下螺旋桨，在各个姿态停稳后执行 turtle_recovery status。
1. 正立水平：tilt 接近 0 度，alignment 接近 +1。
2. 侧立：tilt 接近 90 度，alignment 接近 0。
3. 倒扣水平：tilt 接近 180 度，alignment 接近 -1。
4. 正立时让右侧向下滚动：转动期间 roll rate 应为正；停稳后接近 0。
   角速度是瞬时值，可配合 listener vehicle_angular_velocity 观察转动过程，xyz[0] 单位为弧度每秒。
5. 开关 OFF 到 ON：requests 增加 1；持续 ON 不重复增加。
6. 检查 RIGHT (would select) 是否对应实际机体右侧电机，并与 QGC 执行器映射核对。

本阶段不运行电机，也不向电调发送反转或恢复指令。
完成这些核对之后，下一阶段才开发临时反转、停机、方向恢复和专用输出许可。

+#include <matrix/matrix/math.hpp>

+namespace turtle_recovery
+{
+
+// Alignment of body +Z with earth down. No Euler angle conversion is needed.
+inline bool attitudeAlignment(const float q[4], float &alignment)
+{
+	alignment = NAN;
+	matrix::Quatf attitude{q};
+	const float norm = attitude.norm();
+
+	if (!std::isfinite(norm) || fabsf(norm - 1.f) > 0.02f) {
+		return false;
+	}
+
+	attitude.normalize();
+	alignment = matrix::Dcmf{attitude}(2, 2);
+	return true;
+}
+
+// Logical motor indices, not physical output channels. Only a conventional
+// four-rotor layout with two motors on either side is supported in this stage.
+inline bool rightMotorMask(const float position_y[4], uint32_t &mask)
+{
+	mask = 0;
+	unsigned right_count = 0;
+	unsigned left_count = 0;
+
+	for (unsigned i = 0; i < 4; ++i) {
+		if (!std::isfinite(position_y[i]) || fabsf(position_y[i]) < 1e-4f) {
+			mask = 0;
+			return false;
+		}
+
+		if (position_y[i] > 0.f) {
+			mask |= 1u << i;
+			++right_count;
+
+		} else {
+			++left_count;
+		}
+	}
+
+	if (right_count != 2 || left_count != 2) {
+		mask = 0;
+		return false;
+	}
+
+	return true;
+}
+
+class ObserveTrigger
+{
+public:
+	bool update(bool available, float aux)
+	{
+		if (!available || !std::isfinite(aux) || aux < -1.f || aux > 1.f) {
+			reset();
+			return false;
+		}
+
+		if (aux < -0.5f) {
+			_seen_off = true;
+			_active = false;
+
+		} else if (aux > 0.5f && _seen_off && !_active) {
+			_active = true;
+			return true;
+		}
+
+		return false;
+	}
+
+	void reset() { _seen_off = false; _active = false; }
+	bool active() const { return _active; }
+	bool seenOff() const { return _seen_off; }
+
+private:
+	bool _seen_off{false};
+	bool _active{false};
+};
+
+} // namespace turtle_recovery

+void TurtleRecovery::Run()
+{
+	if (should_exit()) {
+		ScheduleClear();
+		exit_and_cleanup();
+		return;
+	}
+
+	if (_parameter_update_sub.updated()) {
+		parameter_update_s update;
+		_parameter_update_sub.copy(&update);
+		const bool previous_enable = _param_obs_en.get();
+		const int32_t previous_aux = _param_aux.get();
+		updateParams();
+		updateGeometry();
+
+		if (previous_enable != _param_obs_en.get() || previous_aux != _param_aux.get()) {
+			_trigger.reset();
+		}
+	}
+
+	_manual_sub.update(&_manual);
+	_attitude_sub.update(&_attitude);
+	_angular_velocity_sub.update(&_angular_velocity);
+	_vehicle_status_sub.update(&_vehicle_status);
+	_land_sub.update(&_land);
+
+	const hrt_abstime now = hrt_absolute_time();
+	_aux = auxInput();
+	_rc_valid = _manual.valid && _manual.data_source == manual_control_setpoint_s::SOURCE_RC
+		    && fresh(now, _manual.timestamp_sample, 300_ms) && PX4_ISFINITE(_aux) && fabsf(_aux) <= 1.f;
+	_status_valid = fresh(now, _vehicle_status.timestamp, 2_s);
+	_land_valid = fresh(now, _land.timestamp, 2_s);
+	_attitude_valid = fresh(now, _attitude.timestamp_sample, 100_ms)
+			  && turtle_recovery::attitudeAlignment(_attitude.q, _alignment);
+	_tilt_deg = _attitude_valid ? math::degrees(acosf(math::constrain(_alignment, -1.f, 1.f))) : NAN;
+
+	if (!_attitude_valid) {
+		_alignment = NAN;
+	}
+
+	_gyro_valid = fresh(now, _angular_velocity.timestamp_sample, 100_ms)
+		      && matrix::Vector3f{_angular_velocity.xyz}.isAllFinite();
+	_roll_rate_deg_s = _gyro_valid ? math::degrees(_angular_velocity.xyz[0]) : NAN;
+
+	const bool switch_available = _param_obs_en.get() && _rc_valid && _status_valid
+				      && _vehicle_status.arming_state == vehicle_status_s::ARMING_STATE_DISARMED;
+
+	if (_trigger.update(switch_available, _aux)) {
+		++_trigger_count;
+		PX4_INFO("Observe request #%u: tilt %.1f deg, right mask 0x%x (no motor output)",
+			 _trigger_count, (double)_tilt_deg, (unsigned)_right_motor_mask);
+	}
+}

+int TurtleRecovery::print_status()
+{
+	PX4_INFO("Observation only: no actuator publications or ESC commands");
+	PX4_INFO("Enabled: %s, input: AUX%" PRId32, _param_obs_en.get() ? "yes" : "no", _param_aux.get());
+	PX4_INFO("RC: %s, AUX: %.2f, OFF seen: %s, observing: %s, requests: %u",
+		 _rc_valid ? "valid" : "invalid/stale", (double)_aux, _trigger.seenOff() ? "yes" : "no",
+		 _trigger.active() ? "yes" : "no", _trigger_count);
+	PX4_INFO("Vehicle: %s", !_status_valid ? "unknown/stale" :
+		 (_vehicle_status.arming_state == vehicle_status_s::ARMING_STATE_ARMED ? "armed" : "disarmed"));
+	PX4_INFO("Attitude: %s, tilt: %.1f deg, body-down alignment: %.3f", _attitude_valid ? "valid" : "invalid/stale",
+		 (double)_tilt_deg, (double)_alignment);
+	PX4_INFO("Gyro: %s, roll rate: %.1f deg/s (+ = body-right roll)", _gyro_valid ? "valid" : "invalid/stale",
+		 (double)_roll_rate_deg_s);
+	PX4_INFO("Land detector (reference only): %s", !_land_valid ? "unknown/stale" :
+		 (_land.landed ? "landed" : "not landed"));
+	PX4_INFO("Geometry: %s, right logical motor mask: 0x%x", _geometry_valid ? "supported" : "unsupported",
+		 (unsigned)_right_motor_mask);
+
+	if (_geometry_valid) {
+		for (unsigned i = 0; i < 4; ++i) {
+			PX4_INFO("Motor %u: y=%.3f, %s", i + 1, (double)_position_y[i],
+				 (_right_motor_mask & (1u << i)) ? "RIGHT (would select)" : "LEFT");
+		}
+	}
+
+	return PX4_OK;
+}

+TEST(TurtleObserver, AttitudeAcrossFullRoll)
+{
+	for (int degrees = 0; degrees <= 360; ++degrees) {
+		const float angle = degrees * 0.017453292519943295f;
+		const float q[4] {cosf(angle / 2.f), sinf(angle / 2.f), 0.f, 0.f};
+		const float negative_q[4] {-q[0], -q[1], -q[2], -q[3]};
+		float alignment;
+		float negative_alignment;
+		ASSERT_TRUE(attitudeAlignment(q, alignment));
+		ASSERT_TRUE(attitudeAlignment(negative_q, negative_alignment));
+		EXPECT_NEAR(alignment, cosf(angle), 1e-5f);
+		EXPECT_FLOAT_EQ(alignment, negative_alignment);
+	}
